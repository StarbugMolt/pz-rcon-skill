# 96lancerEVO - '96 Mitsubishi Lancer EVO IV (KI5)

Workshop ID: 3647736504
Mod ID: 96lancerEVO
Enabled on server: yes (B42.13 MP)

Built from zero for B42. Engine was a tank. RHD original + LHD conversion (LHD has small handling penalties for "messing with the delicate setup"). 3 front bumpers + tiered rear, fully animated, 4 seats.

## Vehicle Scripts

RCON syntax: `addvehicle "<script>" "<player>"`

| Script | Description |
|--------|-------------|
| `96lancerEVO` | Original right-hand-drive EVO IV |
| `96lancerEVOlhd` | Left-hand-drive conversion (slight handling penalty) |

## Notes
- Tows and is towable.
- **Not recolorable**.
- Armor protection for windows, doors, engine, headlights.

## Use Cases (SIMON voice)
- **"Built like a tank"** narrative drops — perfect for convoy escort or horde-clear aftermath
- Aggressive-driving scenes — SIMON can warn player not to push it too hard
- LHD flavor: "the converted one's a little twitchy"
