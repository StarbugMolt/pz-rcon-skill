# KI5trailers - Trailers! (KI5 / bikinihorst)

Workshop ID: 3330403100
Mod ID: KI5trailers
Enabled on server: yes (B42.13+ MP fully supported)

Pack of 7 trailers + 2 universal wheel sets, fully animated parts (all removable/placeable), 3D craftable extras (tarps, toolboxes, gas cans). Spawn-able with bikinitools for testing.

## Vehicle Scripts

RCON syntax: `addvehicle "<script>" "<player>"`

| Script | Description |
|--------|-------------|
| `TrailerKI5utilityLarge` | Large utility trailer |
| `TrailerKI5utilityMedium` | Medium utility trailer |
| `TrailerKI5utilitySmall` | Small utility trailer |
| `TrailerKI5cargoLarge` | Large cargo trailer |
| `TrailerKI5cargoMedium` | Medium cargo trailer |
| `TrailerKI5cargoSmall` | Small cargo trailer |
| `TrailerKI5livestock` | Livestock trailer |

## Dependencies
- Requires `damnlib` (also on this server — auto-satisfied).
- `bikinitools` is NOT required; only needed for *testing* spawns via cheat menu.

## Notes
- Universal wheel sets mean any KI5 trailer can swap wheels with another — visual variety.
- 3D parts are detachable — players can strip a trailer for parts.
- Safe to add midgame (just enable in the load menu).
- **Not recolorable**.
