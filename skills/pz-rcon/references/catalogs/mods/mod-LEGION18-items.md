# LEGION18 - Legion Weaponry

Workshop ID: 3665548194
Mod ID: LEGION18
Enabled on server: yes (B42 — safe to add mid-save, MP-compatible)

Set of 9 new weapons for the "Second Dawn" RP setting. 3 tiers: standard / advanced / legendary. 4 weapon types: short blunt (×2), axe (×2 + 1 legendary), long blunt (×2), spear (×2). Standard + advanced require a magazine to craft (found in military/police areas). Legendary weapons only from zombie loot. Requires advanced forge to craft.
