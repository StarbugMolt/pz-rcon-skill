# 70fordEscort - '70 Ford Escort (KI5)

Workshop ID: 3670063857
Mod ID: 70fordEscort
Enabled on server: yes (B42.13+ MP)

70s rally legend. 4 chassis variants, 2 front + tiered rear bumpers, fully animated hood/trunk/doors/windows, visible interior, 4 seats. RS variant is fast. Tows and is towable.

## Vehicle Scripts

RCON syntax: `addvehicle "<script>" "<player>"`

| Script | Description |
|--------|-------------|
| `70fordEscortCoupe` | Coupe variant |
| `70fordEscortRS` | RS — fast rally spec |
| `70fordEscortSedan` | Sedan variant |
| `70fordEscortWagon` | Wagon variant (best for hauling) |

## Notes
- All variants share parts — players can mix and match.
- Armor protection for windows, doors, engine, headlights.
- **Not recolorable**.
- Safe to add midgame.

## Use Cases (SIMON voice)
- **"Found a rally legend"** story beat — RS variant spawn after a horde-clear event
- Convoy escort drops — Wagon variant as "support vehicle"
- Fast-reconnaissance narrative — Coupe/RS for scouts
