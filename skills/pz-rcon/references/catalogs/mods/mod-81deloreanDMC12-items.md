# 81deloreanDMC12 - '81 DeLorean DMC-12 (KI5)

Workshop ID: 3253385114
Mod ID: 81deloreanDMC12
Enabled on server: yes (B42.13+ MP)

John DeLorean tribute. Gull-wing doors, fighter-jet cockpit interior, weird part placement, large rear tires, stainless steel chassis. Includes **Back to the Future time machine variant** as optional spawn.

## Vehicle Scripts

RCON syntax: `addvehicle "<script>" "<player>"`

| Script | Description |
|--------|-------------|
| `81deloreanDMC12` | Standard '81 DeLorean DMC-12 |
| `81deloreanDMC12BTTF` | **Back to the Future time machine variant** (optional spawn) |

## Notes
- 2 variants total.
- 3 front bumpers + tiered rear.
- 2 seats only.
- Tows and is towable.
- **Not recolorable**.
