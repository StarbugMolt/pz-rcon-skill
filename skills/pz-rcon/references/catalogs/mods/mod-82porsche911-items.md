# 82porsche911 - '82 Porsche 911 (KI5)

Workshop ID: 3379334330
Mod ID: 82porsche911
Enabled on server: yes (B42.13+ MP)

Classic 911 — turbo, sc, targa, and RWB (Rauh-Welt Begriff). Light, fun, limited storage. RWB is *very* fast, *very* direct, will pull off crazy handbrake moves, will eventually kill you.

## Vehicle Scripts

RCON syntax: `addvehicle "<script>" "<player>"`

| Script | Description |
|--------|-------------|
| `82porsche911turbo` | 911 Turbo — fast |
| `82porsche911sc` | Classic 911 SC |
| `82porsche911targa` | Targa (open-top summer cruiser) |
| `82porsche911rwb` | RWB — extremely fast, will kill you |

## Notes
- 5 front bumpers + 2 rear with 2-tiered protection.
- 2 seats only.
- Tows and is towable.
- **Not recolorable**.

## Use Cases (SIMON voice)
- **Recon / chase scenes** — fast car for horde evasion arcs
- RWB = "you absolute maniac" reward tier — chase sequences end with the player crashing
- Targa = summer/sunny-day narrative beats
- SC = "the classic" — calm, scenic delivery runs
